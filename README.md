# MG7
## Devlog
First, I created the TreeOfBirds class and made sure it could be attached to the Tree GameObject as a Component in the Inspector by making it a Monobehaviour. Then I created three member variables for the class, a float for the interaction distance that can be tunable in the inspector, a Transform component to assign the player's transform component to, and the array for the birds. One small mistake I had made was that I initially put TreeOfBirds[] as the array's class, but when I had to assign the objects to the array, nothing came up. This was because the class had to be Bird, because that was the class attached to the Sparrow GameObjects. Anyways, after I had created and set the array up, underneath the member variables I wrote the Update method because we have to check every frame whether the player and the birds are close enough to activate the Sparrow GameObjects. Inside the Update method, I wrote the for loop that cycles through the _birds array. I always get confused when setting the second paramater in for loops since arrays start at 0, but then I remembered that you could let the computer do the work with the .Length thing. Inside the for loop, I first created a variable that stored the information of each Sparrow in the _birds array. Then, I wrote an if statement that used the Vector positions of the Sparrow's transform position and the player's transform (using the Transform member varible set earlier), and wrote a comparison statement with the _interactionDistance variable. If the parameter was true, I used the SetActive method to set the Sparrow GameObject to true. Initially, I tested out setting _interactionDistance = 3, but that didn't seem to activate all the Sparrows. It only activated Sparrow4, so I decided to make the distance larger in case the Sparrows were too far from the player. The Debug.Log in the if statement was used to further test out whether the code was working.
